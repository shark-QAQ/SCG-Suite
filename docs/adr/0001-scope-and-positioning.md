# ADR 0001: 项目定位与范围

## 状态

已接受（Phase 1）

## 背景

SCG Suite 最初是两个 POC：Python MCP 扫描器与 DSH 正则拦截插件。项目的
核心差异化是**污染驱动的会话级降级**：Agent 接触凭据后，同时收紧文件沙箱
与网络出口，并留下可校验、可回放的审计链。

## 决定

1. 项目定位为 **taint-aware session guard**，核心是运行时强制、数据流防护、
   审计回放；不把自己包装成通用 Agent 控制面。
2. 交付按"开源项目 + 企业级工程质量"设计，**不做**真实 SaaS 的多租户、
   计费、SOC2 或销售体系。
3. **DSH 首发**，但核心策略/事件包不绑定 DSH；后续通过 MCP Proxy 或适配器扩展。
4. `SCG/` 的 Python 扫描器保留为 Code Gate 模块，不再是主产品。

## 后果

- 叙事聚焦：harness 内部机制 + 策略内核 + 可量化基准。
- 不需要为了"像公司"而写无用的控制面。
- Phase 3 的商业化探索被明确排除出主线。
